# PFAD assumption register

The Bible (§2) requires PFAD to keep four things apart: **assumption**, **model
implementation**, **measured result**, **external validation**. This file lists
every assumption and implementation choice the Phase 0 code makes, where it
lives, and why. Experiment records cite these IDs in their `assumptions` field.

A change to any entry is a model change: it gets a new model version, a
`MODEL_CHANGELOG.md` entry and, where it affects physics, an experiment.

| ID | Kind | Statement | Where | Why / status |
|---|---|---|---|---|
| A-01 | Units | Model units: reference particle mass m = 1, diameter d = 1 (r = 0.5), k_B = 1, reference kT = 1. Time unit d·√(m/kT). 2D pressure unit kT/d² (force per unit length). | everywhere | No physical mapping exists yet. Physical ρ, T, μ, V, L enter only through a future, separately validated scaling layer (Bible §22). |
| A-02 | **Deviation from Bible** | PFAD Phase 0 is **two-dimensional** (disks). Occupancy is the area fraction φ = n·π d²/4, not the Bible's volume fraction φ = n·π d³/6. | `occupancy/OccupancyField`, `gas/InitialConditions` | 2D makes wall-scale experiments (boundary layers, trailing edges) affordable with 10³–10⁴ particles. Consequences, all explicit: pressure is a line force; the hard-disk equation of state differs from hard spheres; any mapping to 3D wings needs its own validation. |
| A-03 | Definition | Temperature proxy kT = (peculiar kinetic energy)/(number of particles): each disk has 2 translational degrees of freedom of ½kT each. Globally kT = KE/N (walls exchange momentum, so all 2N velocity components are free). Locally, kinetic energy is measured relative to the cell's mass-weighted mean velocity. | `measurements/PressureEstimator` (`kT`), `occupancy/OccupancyField` (`kT`) | A definition of a measured quantity only. **No equation of state is assumed**: pressure is never computed from kT. |
| A-04 | Initial condition | Positions by random sequential addition without overlap (lattice + jitter for dense packing). Velocities from a named distribution (default 2D Maxwellian); net momentum removed; velocities rescaled once so KE/N = kT exactly at t = 0. Optional uniform flow added afterwards. | `gas/InitialConditions` | Documented initialisation; the rescale is one-time, not a thermostat. Relaxation from non-Maxwellian starts is itself an experiment (Step 8). |
| A-05 | Model (Bible §9) | Hard-disk impulse law exactly as specified: J = −(1+e)v_n/(1/m₁+1/m₂), applied when two disks overlap **and** approach (v_n < 0). | `core/CollisionModel` | Verbatim from the Bible. Tested for momentum conservation, e = 1 energy conservation, e < 1 loss, symmetry, replay. |
| A-06 | Numerical | Time-stepped detection with **rewind-to-contact**: an overlapping, approaching pair is moved back along its straight-line motion to the contact instant, the impulse is applied there, and the pair is advanced by the same time. Exact for an isolated binary collision inside a step. Pairs are processed in grid order, not time order, so a particle's second collision within one step is approximated ("late contact"). | `core/CollisionModel` | Late contacts are counted, checked to be fully explained by within-step event ordering (`lateContactsUnexplained` = 0 in all runs so far), scale ∝ dt, and must stay < 10⁻³ of collisions. Timestep convergence studies quantify the effect on measured quantities. `impulse-at-detection` is kept as a competing numerical model. |
| A-07 | Model (Bible §13) | Energy lost in an inelastic collision, (1−e²)·½μv_n², goes to exactly one explicit destination: `external` (leaves the model, recorded in the ledger) or `internal` (Universe B reservoir, split equally between the two particles). | `core/CollisionModel`, `core/Ledger` | Energy never silently disappears. The ledger residual is the reported "energy error". The equal split is a choice, not a derived result. |
| A-08 | Model (Bible §14) | Planar walls with Maxwell accommodation: probability Aw of diffuse re-emission from a wall Maxwellian at kT_w and wall velocity U_w (2D flux-weighted normal speed √(−2(kT_w/m) ln u), Gaussian tangential), else specular reflection. Same rewind-to-contact timing as pairs. With forces acting, the wall law is evaluated at the contact-instant velocity v_½ + (F/m)(dt/2 − τ) (model p0.5). | `walls/WallModel` | Aw is a microscopic wall parameter, not a viscosity. Wall momentum and energy transfer are recorded per bin. |
| A-09 | Measurement definition | Wall pressure = Σ normal impulse delivered to the wall ÷ (Δt · wall length), in windows that close every `windowCollisions` collisions per particle. | `measurements/PressureEstimator` | Pressure comes **only** from wall momentum transfer (Bible §7). |
| A-10 | Statistics | Time series: Flyvbjerg–Petersen block averaging (SE read at the deepest level that still has ≥ 16 blocks; the largest level SE is kept as `conservativeSe`; plateau test reported). Seeds: independent-sample SE. Intervals: two-sided 95 % Student t. | `measurements/Statistics` | Standard practice for correlated simulation data. A result whose block analysis does not plateau is marked INCONCLUSIVE. |
| A-11 | Diagnostic definition | "No empty space": coarse cells holding ~40 particles on average; a cell with φ < 0.1·φ_mean in 5 consecutive samples raises POTENTIAL MODEL / NUMERICAL FAILURE. | `measurements/EmptySpaceMonitor` | With 40 particles per cell an empty cell is a > 6σ Poisson event, so the flag is not triggered by ordinary noise. Thresholds are choices and are recorded. |
| A-12 | Numerical | Contact grid cell size (default ≈ √(2·area/N), ≥ contact distance) changes the order in which pairs are processed, hence individual trajectories (chaos), but must not change statistics. | `core/Simulation` | Recorded for exact replay; tested by the `static-box/grid` convergence study. |
| A-13 | Model option | Default contact is rigid (impulse law, K → ∞). Alternative: soft contact F = Kδ, E = ½Kδ² (Bible §10), undamped, integrated by velocity Verlet with dt = contact time/25; `deformation` holds the largest current overlap. The two contact laws are alternatives, never combined. | `core/DeformationModel` | Lets experiments vary stiffness; K → ∞ approaching the rigid result is an experiment, not an assumption. |
| A-14 | Numerical | Adaptive timestep dt = clamp(C·d_min/v_max, dt_min, dt_max). | `core/Integrator` | Keeps the largest displacement per step at a fixed fraction C of a diameter while a cooling gas slows down. C is recorded and varied in convergence studies. |
| A-15 | **Hypothesis** (Bible §11) | Occupancy force F = −k_s∇φ, OFF by default. φ from a Lucy kernel of width h; pair weight a_ij = π(r_i² + r_j²)/2 (the particle area for equal disks). Pairwise antisymmetric ⇒ conserves momentum; conservative with U = k_s Σ_{i<j} a_ij W(r_ij). Integrated by velocity Verlet; with hard collisions present, the collision law is evaluated at contact-instant velocities (model p0.2). | `occupancy/OccupancyModel` | The discretisation choices (kernel, h, symmetric weights) are recorded; k_s is calibrated by experiment, never assumed. |
| A-16 | **Hypothesis** (Bible §13) | Universe B reservoir release: after an inelastic collision, a fraction ρ of the pair's internal energy — the reservoirs **after** this collision's own loss has been deposited — is returned to their normal relative motion by a second impulse along n. Exact momentum and total-energy conservation. (Wording clarified 2026-10-07 from the code; behaviour unchanged. Its mean balance is in `UB0_IMPLEMENTATION_RECORD.md` §5.) | `core/CollisionModel` | Lets inelastic parcels form a stable gas without injecting energy. Analogous to translational–internal exchange in molecular gases; whether it gives gas-like behaviour is measured. |
| A-17 | Initial condition | Pressure pulse: the uniform gas is first relaxed (phase 1), peculiar velocities are rescaled once to the target kT, then particles in a central slab get an outward kick ±U. The pulse phase starts a fresh energy ledger. | `experiments/PressurePulseExperiment` | Removes the out-of-equilibrium potential energy of random placement (occupancy/soft contact) and fills the Universe B reservoir before the pulse, so c_p is measured in a steady gas. |
| A-18 | Boundary condition / **measured limitation** | Open (reservoir) boundaries: a particle whose centre crosses the plane is removed; entrants come from a reservoir of stated n, kT and drift U at the kinetic crossing rate n·⟨v_n⁺⟩, with the crossing velocity drawn from the flux-weighted drifting Maxwellian (exact inverse CDF), placed a random fraction of one step's travel inside the plane, overlap re-drawn (counted) or dropped (counted). Optionally the drift is a piecewise-linear function of position along the boundary (entrant positions then ∝ local crossing flux). | `walls/ReservoirBoundary`, `gas/InflowSampling` | The reservoir supplies only the **kinetic** part of the pressure (no excluded-volume/collisional contribution), so a dense interior settles **below** the stated density: measured ≈ 7 % low at φ = 0.05 and ≈ 21 % low at φ = 0.2 (`tests/boundaries.reservoir.test.ts`). Experiments therefore measure and report the realised free-stream state and normalise with it; the stated reservoir state is never used as if it were the realised one. A velocity profile on a far-field boundary is a boundary condition chosen by the experimenter (like a wind-tunnel wall contour), not an aerodynamic law. |
| A-19 | Model / numerical | Solid bodies inside the flow are fixed polygons of straight edges. A disk touches the body when its centre comes within its radius of the polygon boundary; the contact normal is the line from the closest boundary point to the centre — the edge normal on a face, the radial direction at a vertex (a sharp corner is a point contact and is not rounded). The interaction is the planar-wall Maxwell law (A-08) applied along that normal, body at rest; a vertex uses the mean Aw of its two edges. Timing: the earliest contact along the particle's straight path within the step is solved exactly (linear for faces, quadratic for vertices); the particle is moved back to it, re-emitted and advanced for the remaining time. Bodies are processed after pair collisions and planar walls in each step. | `walls/SolidBody` | Lift, drag, surface pressure and shear are sums of these impulses; no force law is involved. The body's impulse enters the momentum ledger and its energy exchange the energy ledger, so conservation residuals stay at round-off (tested). A centre found inside a body halts the run (`INSIDE_BODY`). A particle whose velocity was changed by a pair collision earlier in the same step is traced back along its current velocity (same first-order treatment as planar walls, A-06). |
| A-20 | Boundary condition (Item 3 wall-flow rig) | **Inflow conditioning zone ("fringe")** in a periodic channel. Each step, every particle in x ∈ [x_f0, x_f1) is, with probability 1 − exp(−ν dt), given a velocity from a drifting Maxwellian (U_f(x), kT), where U_f falls linearly from U_a (entrance) to U_b (exit). The particle is also moved to a uniformly random height at the same x if no disk overlaps there. Its velocity change is ledgered as external work and impulse. During start-up only, U_a is PI-controlled to hold the lead-in mass flux at n₀ m U H_in, and U_b relaxes to the lead-in mean velocity. Both are then frozen. | `experiments/WallFlowRun` | It is the experiment's controlled bulk-flow condition: an inlet spread over a zone upstream of the test section, playing the role of a closed-circuit wind tunnel's fan and settling chamber. It conserves the particle count exactly and keeps the energy and momentum ledgers closed. Nothing acts on the gas in the test section. The realised inflow state (mass flux, velocity, density, kT) is measured and reported per case. Its parameters are documented choices (`docs/CRITERIA_BOUNDARY_LAYER_SEPARATION.md` §3.3). |
| A-21 | **Model** (UB-0 coarse-graining map; design review d068755 §2, A1) | 𝓜_{N_c}: a parcel of N_c molecules has M = N_c m, D = √N_c d (φ_p = φ), E_int = (N_c − 1)kT, restitution e (choice), release fraction ρ_rel = (1 − e²)/(2(N_c − 1) + 1 − e²) (derived: the mean balance of A-16 as coded at T_kin = T_int; corrected from the design's (1 − e²)/(2(N_c − 1)) by amendment A2, D2, a derivation erratum — `UB0_IMPLEMENTATION_RECORD.md` §5), occupancy stiffness k_s = (N_c − 1)K_T,A/(nφ) evaluated at the mapping state point φ = 0.2 (mean-field closure on Universe A's isothermal modulus), Lucy kernel width h = c_h √N_c D (choice). N_c = 1 is the identity (Universe A). | `universeB/CoarseGrainMap` | The only Universe A value that sets a Universe B parameter is K_T,A (Stage 0). No Universe B observable sets any parameter. k_s is a fixed model constant: a run at another density changes only the parcel count. |
| A-22 | Measurement method (UB-0) | Viscosity from the free decay of an imposed transverse wave u_x = U₀ sin(2πy/L): nonlinear least squares in linear amplitude, A(t) = A₀ exp(−νk²s), in thermal time s = ∫√(T_kin/T₀)dt, over s ∈ [0.1 τ_D, min(1.5 τ_D, s_end)], τ_D = L²/(4π²ν_D), ν_D = 0.351/ρ (fixed, A1 §4.2). Fourier-projected shear stress decomposed into kinetic, collisional and occupancy parts. | `universeB/UB0Run`, `universeB/UB0Estimators` | Thermal time is exact for hard disks and approximate when an athermal occupancy part exists (design §11.4). τ_D is fixed in advance so no run length depends on a result. |
| A-23 | Initial condition (UB-0) | Preparation: random non-overlapping placement; 100 D/σ_v of full dynamics; **one** global rescale of centre-of-mass peculiar velocities (KE = N kT) and reservoir energies (mean (N_c − 1)kT), net momentum removed (periodic kinds only); 20 D/σ_v more; then the wave or the measurement. | `universeB/UB0Run` | A state preparation, logged, never repeated: not a thermostat. Wall and Couette boxes are prepared by their Maxwell walls instead. |
