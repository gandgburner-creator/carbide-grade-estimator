# PFAD assumption register

The Bible (§2) requires PFAD to keep four things apart: **assumption**, **model
implementation**, **measured result**, **external validation**. This file lists
every assumption and implementation choice the Phase 0 code makes, where it
lives, and why. Experiment records cite these IDs in their `assumptions` field.

A change to any entry is a model change: it gets a new model version, a
`MODEL_CHANGELOG.md` entry and, where it affects physics, an experiment.

| ID | Kind | Statement | Where | Why / status |
|---|---|---|---|---|
| A-01 | Units | Model units: reference particle mass m = 1, diameter d = 1 (r = 0.5), k_B = 1, reference kT = 1. Time unit d·√(m/kT). 2D pressure unit kT/d² (force per unit length). | everywhere | No physical mapping exists yet. Physical ρ, T, μ, V, L enter only through a future, separately validated scaling layer (Bible §22). |
| A-02 | **Deviation from Bible** | PFAD Phase 0 is **two-dimensional** (disks). Occupancy is the area fraction φ = n·π d²/4, not the Bible's volume fraction φ = n·π d³/6. | `occupancy/OccupancyField`, `gas/InitialConditions` | 2D makes wall-scale experiments (boundary layers, trailing edges) affordable with 10³–10⁴ particles. Consequences, all explicit: pressure is a line force; the hard-disk equation of state differs from hard spheres; any mapping to 3D wings needs its own validation. |
| A-03 | Definition | Temperature proxy kT = (peculiar kinetic energy)/(number of particles): each disk has 2 translational degrees of freedom of ½kT each. Globally kT = KE/N (walls exchange momentum, so all 2N velocity components are free). Locally, kinetic energy is measured relative to the cell's mass-weighted mean velocity. | `measurements/PressureEstimator` (`kT`), `occupancy/OccupancyField` (`kT`) | A definition of a measured quantity only. **No equation of state is assumed**: pressure is never computed from kT. |
| A-04 | Initial condition | Positions by random sequential addition without overlap (lattice + jitter for dense packing). Velocities from a named distribution (default 2D Maxwellian); net momentum removed; velocities rescaled once so KE/N = kT exactly at t = 0. Optional uniform flow added afterwards. | `gas/InitialConditions` | Documented initialisation; the rescale is one-time, not a thermostat. Relaxation from non-Maxwellian starts is itself an experiment (Step 8). |
| A-05 | Model (Bible §9) | Hard-disk impulse law exactly as specified: J = −(1+e)v_n/(1/m₁+1/m₂), applied when two disks overlap **and** approach (v_n < 0). | `core/CollisionModel` | Verbatim from the Bible. Tested for momentum conservation, e = 1 energy conservation, e < 1 loss, symmetry, replay. |
| A-06 | Numerical | Time-stepped detection with **rewind-to-contact**: an overlapping, approaching pair is moved back along its straight-line motion to the contact instant, the impulse is applied there, and the pair is advanced by the same time. Exact for an isolated binary collision inside a step. Pairs are processed in grid order, not time order, so a particle's second collision within one step is approximated ("late contact"). | `core/CollisionModel` | Late contacts are counted, checked to be fully explained by within-step event ordering (`lateContactsUnexplained` = 0 in all runs so far), scale ∝ dt, and must stay < 10⁻³ of collisions. Timestep convergence studies quantify the effect on measured quantities. `impulse-at-detection` is kept as a competing numerical model. |
| A-07 | Model (Bible §13) | Energy lost in an inelastic collision, (1−e²)·½μv_n², goes to exactly one explicit destination: `external` (leaves the model, recorded in the ledger) or `internal` (Universe B reservoir, split equally between the two particles). | `core/CollisionModel`, `core/Ledger` | Energy never silently disappears. The ledger residual is the reported "energy error". The equal split is a choice, not a derived result. |
| A-08 | Model (Bible §14) | Planar walls with Maxwell accommodation: probability Aw of diffuse re-emission from a wall Maxwellian at kT_w and wall velocity U_w (2D flux-weighted normal speed √(−2(kT_w/m) ln u), Gaussian tangential), else specular reflection. Same rewind-to-contact timing as pairs. | `walls/WallModel` | Aw is a microscopic wall parameter, not a viscosity. Wall momentum and energy transfer are recorded per bin. |
| A-09 | Measurement definition | Wall pressure = Σ normal impulse delivered to the wall ÷ (Δt · wall length), in windows that close every `windowCollisions` collisions per particle. | `measurements/PressureEstimator` | Pressure comes **only** from wall momentum transfer (Bible §7). |
| A-10 | Statistics | Time series: Flyvbjerg–Petersen block averaging (largest SE over levels with ≥ 16 blocks; plateau test reported). Seeds: independent-sample SE. Intervals: two-sided 95 % Student t. | `measurements/Statistics` | Standard practice for correlated simulation data. A result whose block analysis does not plateau is marked INCONCLUSIVE. |
| A-11 | Diagnostic definition | "No empty space": coarse cells holding ~40 particles on average; a cell with φ < 0.1·φ_mean in 5 consecutive samples raises POTENTIAL MODEL / NUMERICAL FAILURE. | `measurements/EmptySpaceMonitor` | With 40 particles per cell an empty cell is a > 6σ Poisson event, so the flag is not triggered by ordinary noise. Thresholds are choices and are recorded. |
| A-12 | Numerical | Contact grid cell size (default ≈ √(2·area/N), ≥ contact distance) changes the order in which pairs are processed, hence individual trajectories (chaos), but must not change statistics. | `core/Simulation` | Recorded for exact replay; tested by the `static-box/grid` convergence study. |
| A-13 | Model gap | No deformation: contact is instantaneous and rigid (stiffness K → ∞). `deformation` is carried in the particle state but is zero. | `core/ParticleStore` | The Bible's F = Kδ contact model (§10) is a replaceable `DeformationModel` still to be implemented; experiments that vary stiffness cannot run until it is. |
| A-14 | Numerical | Adaptive timestep dt = clamp(C·d_min/v_max, dt_min, dt_max). | `core/Integrator` | Keeps the largest displacement per step at a fixed fraction C of a diameter while a cooling gas slows down. C is recorded and varied in convergence studies. |
